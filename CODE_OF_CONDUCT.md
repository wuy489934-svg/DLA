# Code of Conduct

## Our pledge

We want participation in DLA to be harassment-free for everyone, regardless of experience, identity, or background.

## Expected behavior

- Be respectful and assume good faith.
- Critique code and ideas, not people.
- Do not publish private data, API keys, device identifiers, or captured conversations.
- Respect the security disclosure process.

## Unacceptable behavior

Harassment, threats, discriminatory language, doxxing, and publishing another person's private information.

## Enforcement

Maintainers may remove comments, close issues, or block contributors who violate these rules. Report concerns privately to the maintainer.
