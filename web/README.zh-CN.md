# DLA Web UI

DLA 的 WebView 前端：聊天、Agent 事件、迭代树、上下文与用量展示。

DLA 是独立的 Android 本地智能体项目，不是官方 Demo 的打包壳，也不是其它 Android Agent 的 UI 复刻。

## 上游与许可

Web UI 基于 [deepseek-ai/chat-demo](https://github.com/deepseek-ai/chat-demo)（MIT）。DLA 的 Agent 引擎、原生工具层、调度器、迭代树、诊断与评测为独立实现。

上游 MIT 文本保留在 `LICENSE`；DLA 项目整体许可见仓库根目录。
