# DLA 3.1.2 更新说明

## 一句话

这次不加新玩具，修三件事：**轮数、用量可见性、结论可信度**；首页拆成 LLM / Agent 两个互不混排的分区。

## 首页与配色

- 首页只保留两个分区入口（LLM 对话 / Agent 任务），各自带会话数。
- 会话列表收进各自分区，互不混排；返回链路：聊天 → 所属分区 → 首页。
- Agent 用薄荷绿（主色），LLM 用暖色，扫一眼就知道自己在哪个区。

## Agent：轮数

- 单轮上限 **40 → 120**，长任务不再频繁弹「继续」。
- 调用指南明确：一条 `phone_sh` 命令可以用 `;` / `&&` 串联多条语句，同一轮也可以同时发出多个工具调用。
- 模型如果连续 6 轮只发一个同名工具，会在工具结果里收到一次批量提示（第 6 / 12 / 18… 轮）。

## Agent：用量可见

- **上下文用量条**：十段虚线，每段代表 10%，段内按比例填充；百分比最低显示 1%、精确到 0.1%。
- 窗口大小可在「设置 → 模型接口」选择 64K / 128K / 256K / 1M（默认 128K）。
- **本轮耗时**：从你发出消息到这一轮结束，只记这一轮、不累计；运行中实时走，结束后定住。
- 迭代树折叠头的耗时也改用这个真实墙钟时间。
- 用量会随消息落盘，重开会话还能看到上次的值。

## Agent：结论可信

- 调用指南按三种**执行身份**组织：
  - `phone_sh` / `phone_py` / `phone_js` = 应用身份（不能跑 `pm` / `am` / `settings` / `dumpsys`，也看不到 `/proc` 全局）；
  - `phone_shell` = Shizuku（uid 2000，特权命令只在这里可用）；
  - 无障碍工具只做界面操作。
- **负证据无效**：应用身份下 `ps -A` 只有自己那几个进程，`/proc/net/tcp`、`ss`、`/data/app` 都读不到；“没看到”不等于“没在跑”。
- **先测再断言**：说“不可用 / 没权限”之前先实测一次；没测就写“未验证”，不写“应该”。
- 每次运行开始时注入**本机运行时快照**（无障碍开/关、Shizuku 就绪/未就绪、内置运行时身份），模型不必再猜。
- 工具卡展开后显示**执行身份**（应用身份 / Shizuku uid 2000），看懂为什么 `pm` 在 `phone_sh` 里会失败。

## 修复

- 工具卡「详情」以前读错事件字段，结果一直为空；现在参数和结果都能看到。
- 会话列表以前不显示「N 轮 N 步」；现在每次回复都会写入用量统计并展示。

## 升级提示

- 覆盖安装保留会话、人设与 API Key。
- 覆盖安装会清掉系统无障碍启用项，装完需要重新打开（Agent 的读屏 / 点按要用）。
- 仅支持 arm64-v8a，APK 约 48 MB，需要 Android 10+。
- 与 v3.0 同包名同签名，可直接覆盖升级。
