# DLA 2.5 更新说明

## 一句话

助手会说话了：默认用本机系统语音朗读回复，也可以自己接入任意 OpenAI 兼容的云端 TTS；
角色的设定从一个大文本框拆成五个分层，AI 可以补全，也可以从一张图里读出外貌。

## 朗读（TTS）

- 设置 → 对话 →「朗读回答（TTS）」开关；打开后回复结束自动朗读。
- 每条助手正文下有「🔊 朗读」，再点一次停止；长消息会自动截断到合理长度。
- 默认引擎是**本机系统语音**（离线、免费、零配置）；没有系统引擎时设置页会显示原因，并提供「打开语音设置」。
- **自定义语音提供商**：设置 → 对话 →「添加语音提供商」，填名称、Base URL、API Key、模型、音色、格式、语速。
  协议是 OpenAI 兼容的 `POST {Base URL}/audio/speech`（Body: model / input / voice / response_format / speed）。
  支持试听、编辑、删除、切换；密钥只保存在本机。
- 试听会真实合成并播放一次，失败会显示 HTTP 状态或服务端错误，不会静默失败。

## 角色设定

- 五个分组、十个字段：核心身份（名字、身份、外貌）、性格与表达（性格、说话风格、情感表达）、
  关系与背景、边界与底线、补充。旧版单段人设会自动迁移到「补充」。
- **AI 补全设定**：模型会先考虑情感需求、事实定义、用户安全，再补全空字段；
  结果先预览，只写空的，不覆盖已有内容；另有「清空」用于重新开始。
- **上传图片分析**：压缩后交给模型分析，填补外貌/身份/性格，可「应用并设为立绘」。
- **文字优先**：如果图片与文字设定冲突，以文字为准；图片只补充文字没写到的细节。

## 升级提示

- 覆盖安装即可保留会话、角色设定与 API Key；升级前建议导出一次历史。
- 重装后系统的无障碍开关可能被清掉，需要重新打开（Agent 用）。
- 2.5 仍只支持 arm64-v8a；APK 约 48 MB。
