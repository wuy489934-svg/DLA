# DLA 的定位

## 一句话

**手机 Agent 的执行力 + LLM 人设的陪伴感，两个平级分区，一个本地 APK。**

## 26.11.4 的定位：平级 · 可信 · 能自检 · 能持续思考

四个关键词分别对应结构、证据、产物与长任务：

1. **平级**：LLM 区与 Agent 区不是「聊天框旁边挂了个工具面板」，而是同一款产品的两张脸。首页只给两个入口，会话各自隔离，配色区分（Agent 薄荷绿 / LLM 暖色），共用同一套模型接口与本机数据。
2. **可信**：Agent 的每一条结论都要能追溯到「哪个身份、哪次调用、哪条证据」。运行时先把本机能力实测一遍写进 system（无障碍、Shizuku、内置运行时），工具结果带 `[工具 · 身份]` 来源标签，指南禁止把 Shizuku（uid 2000）跑通的结论记到应用身份头上，也禁止拿应用身份看不到的负证据（`ps -A`、`/proc/net`、端口探测）当结论。
3. **能自检**：Agent 交付的东西不靠嘴说“做好了”。`phone_web_shot` 能在 DLA 自己的窗口里离屏渲染生成的 HTML 并回传截图，模型看图修版式；输出被 `max_tokens` 截断会自愈（分段重写）或自动续写，而不是把任务停掉。
4. **能持续思考**：长任务保持「思考 → 调用 → 思考」。思考超限只让当前这一轮直接执行，下一轮恢复思考；被截断的思考尾巴接回提示；连续想过头只收紧本轮预算（12K → 6K → 3K）。同时按 Anthropic / DeepSeek 的要求回传 thinking 块（含 signature），否则工具调用的下一轮会 400。

## 是什么

DLA = **DeepSeek LLM Agent**，一个运行在 Android 系统内的本地智能体客户端。

- **模型接口**：一套设置（协议 + Base URL + API Key + 模型 + 供应商）同时服务两个区，支持 **Anthropic Messages** 与 **OpenAI Chat Completions** 两种方言；内置 12 个供应商预设（DeepSeek、通义千问 / 百炼、Kimi、GLM、OpenAI、Claude、OpenRouter、硅基流动、Groq、Ollama、自定义…）与按 Base URL / 模型名的自动识别。
- **原生 Android 工具层**：无障碍、PackageManager、Shizuku、文件/设置/截图，以及自带 shell / Python / Node / ripgrep。
- **原生 Agent 引擎**：流式请求、工具调度、并行组、迭代树、审批、checkpoint、运行日志与重启认领。
- **原生 Compose 界面**：页面栈（首页 → 分区 → 会话 → 设置）、双分区、审批、迭代树、上下文用量条、设置卡片；唯一界面，没有网页外壳。
- **本地优先**：会话/设置/诊断在本机；API 请求直达用户配置的端点。

## 适合谁

- 想要一个**可自定义人设、能长期聊、还能朗读**的 AI 伴侣 / 角色扮演对象的人；
- 想在手机上**让 AI 真的动手**（读屏点按、跑脚本、整理文件、查应用与系统信息、写网页并自己检查效果）的人；
- 需要**结论可追溯**的人：模型用了哪个身份、调了哪个工具、哪几条是实测、哪几条是“未验证”，界面上都能看到；
- 在意**数据留在本机**、不要账号与遥测的人；
- 想读源码、自己编译、确认「它到底能做什么」的人。

## 不是什么

- **不是官方 Demo 的打包壳**：早期版本曾使用 MIT 许可的网页 UI 作为外壳，现在已完全替换为原生 Compose；DLA 的 Agent 引擎、原生工具、调度器、迭代树、诊断和评测是独立实现。
- **不是其它 Android Agent 的复刻**：不复制其 UI、资源或实现；DLA 的差异是 Android 原生工具 + 系统内运行 + 小体积。
- **不是 Termux 前端 / Termux 包装**：Termux 集成已在 2.2 整体删除，不是可选后端；shell / Python / Node / ripgrep 全部内置。
- **不是自带 Linux 发行版**：DLA 自带 Android 的 toybox shell、CPython 3.12、Node 24 与 ripgrep，够跑命令和脚本；但不打包发行版、包管理器或通用终端生态（没有 `pip` / `npm` 安装、没有 `curl` / `wget`）。
- **不是多代理框架**：默认单 Agent；只有在明确、只读、有预算的场景才考虑有界子任务。
- **不是万能搜索 / 抓取**：`web_fetch` 是原生抓取（静态 HTML / JSON / 纯文本），`web_search` 在非 DeepSeek 端点上走免费网页后端，可能被反爬或受网络影响；失败信息会带诊断，但结果质量不如付费搜索 API。

## 设计约束

1. **原生优先**：能用 Android API 就不 fork 子系统进程；Agent 单独跑在 `:agent` 进程，只为把任务与界面崩溃隔离，不是新的运行时。
2. **系统内运行**：前台服务、无障碍、Shizuku 都在手机内完成。
3. **小巧但全能**：单 APK，不引入重型运行时。
4. **可信执行**：身份、证据、来源对用户可见；工具耗时、并行组、缓存、上下文、失败原因都能看到；“没测”必须标“未验证”。
5. **开源**：Apache-2.0；保留第三方许可；不捆绑不可再分发素材。

## 品牌与素材

- 应用名 / 核心检索词：**DLA**（DeepSeek LLM Agent）；搜索、引用、发版都用这个名字
- 发布版 = 开源版：仓库里的 `android/` 就是完整应用，Release 由本仓库源码构建；没有内部版、没有隐藏功能
- 图标与吉祥物：本项目原创 **v1 Cue**（深墨绿 `#0A1312` 底板 + 薄荷色终端小精灵 + 暖色天线/命令条）作为应用图标与思考态头像；首页主视觉为 **v2 溟灯**（分层光效）。三版提案与规格见 `docs/mascot/`，预览见 `docs/assets/`
- 镜子模式：代码保留，但公开版**不内置**人设文本与立绘；资产缺失时界面显示「未内置人设」
- 上游 Web UI：deepseek-ai/chat-demo，MIT；早期版本曾作为外壳使用，现在已由原生 Compose 完全替代
- 不包含官方 Demo 的角色素材或未授权插画
- 存储 key 中保留 `chat-demo:*` 仅用于兼容旧数据，不代表产品身份
