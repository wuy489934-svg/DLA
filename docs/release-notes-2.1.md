# DLA 2.1 更新说明

> **历史说明（重要）**：本文对应旧版本，其中提到的 Termux 集成已在 2.2 整体删除。当前版本（3.6.0）不使用、不支持 Termux，也没有“可选 Termux 后端”；下面的 Termux 描述仅作历史记录。

> 面向用户的版本说明。发布时把本文件的内容贴到 GitHub Release；正文里的
> `DLA.apk` 与 `SHA256SUMS` 由发布流程生成。

## 一句话

2.1 是把 2.0 打磨到「日常顺手」的一版：消息能复制了，空会话不再占列表，输入一半的草稿会留着，
点「继续」能接上之前的上下文，工具耗时按单次显示，Agent 也能真正“看”本机图片了。

## 升级方式

- **直接覆盖安装，不要先卸载**：包名仍是 `io.github.dla.agent`，版本号 `versionCode 37 / versionName 2.1`。
- 从 2.0 升级会保留本机会话、草稿与设置（同包名、同签名）。升级前仍建议在设置 → 数据管理里导出一次历史。
- 2.1 的默认值没有变：逐次审批、完全权限默认关闭、无遥测、不需要账号。

## 界面与输入

- **长按复制**：长按用户消息或回答段落，会弹出「复制文本」面板——「复制全部」一键拿走整条内容；
  面板里的文字可以长按拖选其中一段。回答下方还常驻一个「⧉ 复制」小按钮。
  列表照常上下滑动，不会因为长按变成整屏选择态。
- **空会话不再保存**：新建会话只在内存里，等你发出第一条消息、或往输入框里打了字，才写入磁盘。
  旧版本留下的「0 条」空壳会在启动时清理。
- **草稿保留全貌**：输入框内容按会话保存（防抖 500ms，离开会话立即落盘），下次打开同一个会话会恢复原文；
  只有草稿的会话在列表里显示「草稿：前 16 个字」，一眼能看出是没写完的内容。
- **图片预览改成非全覆盖**：点聊天里的图片，居中显示（宽 90%、高 72%），四周仍能看到对话，
  点任意位置或按返回关闭。

## Agent

- **「继续」带完整上下文**：请求会带上最近 8 轮的对话（助手一轮附工具调用摘要），连续同角色消息自动合并；
  上一轮的计划与笔记会以 `resumeTaskState` 回传。所以轮到上限后说「继续」，模型能接着做，
  而不是回你“当前会话是空的”。
- **读图工具 `phone_view_image`**：给一个图片路径（jpg/png/webp/gif），工具会把图片按长边 1280、
  JPEG 82 压缩后作为图片块回传，模型下一轮就能看到画面内容；超过 32MB 或解不出来会直接说明原因。
  这个工具**不需要 Shizuku**——只是读文件，Termux-only 的设备同样可用。
- **工具耗时按单次显示**：原来是「运行开始到现在」，长任务里会滚成 `1484111ms` 这种数字；
  现在每条工具显示自己那一次的耗时，并按 `820ms / 4.3s / 2m 43s / 7h 12m` 格式化。

## 隐私

- 读图是把**你指定的那张图片**压缩后随请求发给你自己配置的模型端点，和发附件是同一路径；
  项目本身不落地、不中转、不上报。不想发就不调用这个工具。
- 草稿、计划、笔记都只写在本机的会话 JSON 里，导出历史时「草稿」字段不进导出。

## 已知限制

- 仍需 Android 10+（`minSdk 29`），targetSdk 36。
- 执行后端仍要求 Shizuku 或 Termux 至少一个可用；纯 Termux 时只能用不依赖特权的工具（读图、读文件、termux 等）。
- 老会话里已存的工具耗时是旧算法算出来的偏大值，不会回溯修正；新运行才准确。
- 复制面板给的是 Markdown 原文（`**加粗**` 会原样带出），不是渲染后的纯文本。
- `phone_view_image` 只读静态图片，GIF 取首帧，不支持视频。

## 校验

发布产物为 `DLA.apk` 与同目录的 `SHA256SUMS`：

```bash
sha256sum -c SHA256SUMS
# 或
certutil -hashfile DLA.apk SHA256
```

APK 的 `package / versionCode / versionName` 应为 `io.github.dla.agent / 37 / 2.1`。
