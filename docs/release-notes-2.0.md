# DLA 2.0 更新说明

> 面向用户的版本说明。发布时把本文件的内容贴到 GitHub Release，正文里的
> `DLA.apk` 与 `SHA256SUMS` 由发布流程生成。

## 一句话

2.0 把 DLA 从「WebView 壳」变成了**原生界面 + 独立 Agent 进程**：界面是 Jetpack Compose 写的，
Agent 跑在单独的 `:agent` 进程里，点停止会连 Termux 里本次启动的整棵进程树一起结束。

## 升级方式

- **直接覆盖安装，不要先卸载**：包名仍是 `io.github.dla.agent`，版本号 `versionCode 31 / versionName 2.0`。
- 升级前建议在设置 → 数据管理里导出历史；会话数据仍保存在本机。
- 2.0 首次启动会尝试把网页版 `localStorage` 里的 API Key 迁移到原生设置，只在新位置为空时写入，不会覆盖你已经填好的值。

## 新的界面

- **原生 Compose**：会话列表、聊天、流式输出、审批卡、迭代树、设置全部原生绘制。
- **Markdown 原生排版**：标题、列表、表格、引用、代码块不再由 WebView 承载，快速滑动时不会出现文字忽隐忽现或高度跳变。
- **公式与流程图离线渲染**：KaTeX 与 mermaid 已内置在 APK 里，不需要联网、不会去 CDN 取资源。
- **网页界面还在**：设置 → 界面 → 打开网页界面；它现在是兼容外壳，随时可以回去。

## Agent 的变化

- **独立进程**：Agent 服务跑在 `:agent` 进程，界面崩溃、被系统回收或重建都不会带走正在跑的任务；重新打开界面会按事件游标接上。
- **停止更彻底**：以前点停止只让 DLA 不再等待，Termux 里 fork 出来的 npm / python / 下载仍会继续。现在每次运行都有 `runId`，停止时会终止对应的进程组（带 `pkill -f` 兜底），2 秒后仍未退出则强制 KILL。
- **长任务可观察**：通知栏显示当前任务并可紧急停止；工具耗时、缓存、并行组、迭代树都在界面里。

## 附件与多语言

- 原生输入栏支持**图片、PDF、docx、纯文本/代码**：图片按长边压缩，PDF 逐页渲染成图片再交给模型，docx 提取正文。
- **一次可挑多个文件**：选中后在输入框上方以标签列出，可逐个移除；发给 Agent 的附件会先复制到应用目录，工具能直接按路径读取同一份文件。
- **中英双语**：界面文案、错误提示、审批卡都会跟随语言设置；可以选中文 / English / 跟随系统。
- **主题与反馈**：深色 / 浅色 / 跟随系统，界面音效可开关。

## 吉祥物与图标

- 首页是 **v2 溟灯（深海信标）** 的分层光效：呼吸、漂浮、旋转光晕与漂移光斑；思考态是 **v1 Cue（终端小精灵）** 头像 + 标题呼吸。
- 动效只改绘制层与 `graphicsLayer`，不触发测量，滚动会话列表时不会掉帧。
- 新图标是 **v1 Cue**：方形、圆形、自适应前景（`#0A1312` 底板）与单色主题图标都由同一份素材生成。
- 三版吉祥物提案（v1 图标与思考头像、v2 首页立绘、v3 备选）见仓库 `docs/mascot/`；v3 只做选型存档，不参与构建。

## 隐私与安全

- **数据不出手机**：会话、设置、诊断只在本机；模型请求直达你自己填写的 DeepSeek 兼容端点，项目不做中转、不接入遥测、不需要账号。
- **不是沙箱**：Agent 需要读屏、枚举应用、执行 shell 才能干活，所以默认逐次审批，“完全权限”默认关闭。
- **开源版不含任何人设资产**：镜子模式保留为代码能力，但公开包里没有内置人设文本与立绘，设置页会显示「未内置人设」；需要时由使用者自行放入。
- 仓库里不包含 API Key、keystore、本机路径或私人素材。

## 已知限制

- 仍需 Android 10+（`minSdk 29`），targetSdk 36。
- 执行后端仍要求 **Shizuku 或 Termux 至少一个可用**；两者都没有时会禁止发送并提示开启路径。
- 无障碍读屏在部分定制系统上可能被系统限制；必要时用 Termux / Shizuku 兜底。
- 公开版按 `RELEASING.md` 的流程签名发布；本地自编译的 debug/unsigned 包不能覆盖安装到已发布的正式包上。

## 校验

发布产物为 `DLA.apk` 与同目录的 `SHA256SUMS`：

```bash
sha256sum -c SHA256SUMS
# 或
certutil -hashfile DLA.apk SHA256
```

APK 的 `package / versionCode / versionName` 应为
`io.github.dla.agent / 31 / 2.0`。
