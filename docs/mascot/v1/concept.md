# v1 · Cue（提示仔）— 终端小精灵

> **一句话设定：** 从一次还没按下的回车键里冒出来的终端精灵——光标是眼睛，暖色命令条是嘴，把复杂的命令行变成一件可以托付的小事。

## 性格 3 条

1. **好奇**：看到任何新命令都想凑近看一眼，眼睛会像光标一样轻轻闪。
2. **利落**：回车即执行，不卖萌拖延；动作短、有回执感。
3. **有分寸的玩心**：可以开玩笑，但运行、等待、出错三种状态一眼可辨。

## 外形要点

- 主体是一块**圆角终端窗**：顶栏三枚窗控点，深色屏幕就是它的脸。
- 眼睛是两枚**光标块**，嘴是一条**暖杏色命令横条**；头顶一枚方块光标天线，像等待下一次输入。
- 方块手掌、方块脚，四肢短而稳。它先像“生物”，再像“设备”，不是一台会走路的显示器。
- 只靠可数的几何块面：外壳、屏幕、两只眼睛、一条嘴、一根天线、两只手、两只脚。
- 小尺寸优先级：**方壳 → 天线 → 双眼 → 方块脚**，其余细节可以全部消失。
- 无渐变、无细描边、无纹理；轮廓和负空间承担全部识别度。

## 为什么适合 DLA

- **最直接的能力隐喻**：DLA 的差异点是 Agent 能调用内置运行时和手机能力执行命令。Cue 把“命令行”变成角色，用户看到它就会联想到“这件事它能替我跑完”。
- **双模式适配**：对话模式下，深色屏幕是一张有表情的脸；Agent 模式下，同一块屏幕可以变成任务状态面板，不换角色就能切换语境。
- **可靠感**：外壳闭合、重心低、姿态稳，符合“本地执行、结果可回执”的产品气质；暖色嘴部把“极客”拉回有温度的一侧。
- **不幼稚**：造型有设备感，性格像同事而不是宠物。
- **可延展**：眨眼、光标移动、命令条伸缩、屏幕扫描线、任务完成的三格状态，都能在原 SVG 分组内完成。

## 与配色如何配合

| 用途 | 颜色 | 说明 |
|---|---|---|
| 外壳 | `#7FE7C4` 薄荷绿 | 大面积主色，在深墨绿背景上足够亮，形成图标级的实心轮廓 |
| 屏幕 | `#0A1312` 深墨绿 | 用负空间做脸，避免再加边框；与 App 背景同色，画面更整 |
| 窗控点 / 暗部 | `#0F3A32` | 让“窗”的结构可读，但不与屏幕抢注意力 |
| 四肢 | `#4FC9A8` | 薄荷的低一档明度，区分肢体、手、脚，仍属于同一色相 |
| 提示点 | `#FFC48A` 暖杏 | 只出现在天线光标与嘴部，严格作为 1 个点缀色 |

在浅色背景上，优先把它放进深色容器或使用 icon 版；主形象本身的深屏需要深底承托。

## 三种使用场景怎么画

### 首页

- **位置**：欢迎区右侧或输入框上方，宽约 120–160 dp 的全身版；不压主 CTA。
- **姿态**：站立，微微右倾，右手抬起；左臂自然下垂，像刚执行完一条命令。
- **动效**：2.4 s 一次的 2–4 dp 上下浮动；每 4–6 s 做一次单眼光标缩短的眨眼；持有新任务时天线光标轻轻下压再回弹。
- **静态关键帧**：双眼完整、嘴为完整命令条，状态色只用暖杏，不用红色错误点。

### 空状态

- **画面**：只露出屏幕上半部和一只搭在输入框边缘的手，身体藏在输入框或面板后面；画面中央到输入框之间保留大面积负空间。
- **姿态**：眼睛看向输入框方向，嘴收短成一条等待输入的小横条。
- **情绪**：不是“这里什么都没有”的空，而是“我在这儿，等你的第一条命令”。
- **注意**：空状态的说明文字由 UI 文案承担，角色图内不加任何文字。

### 加载态

- **画面**：外壳保持不动，屏幕上两只眼睛压成短光标；嘴部命令条改成三段进度块，从左到右亮起。
- **动画**：每段 180 ms，循环时留 300 ms 停顿；不要旋转整个角色，避免廉价 spinner 感。
- **静态帧**：第一段完整、第二段半亮、第三段只剩一个点；下方保留角色外壳，提示“仍在本地运行”。
