# v3 · 铆铆（Nomi）— 助手机器人

> **一句话设定：** 由几块圆角几何体拼成的小助手，胸口那点暖光就是只在本机燃烧的算力，随时准备替你把事情做完。

## 性格 3 条

1. **热心**：先抬手打招呼，再听你说话；遇到任务不推诿。
2. **条理清楚**：动作、状态、反馈都有明确分区，像一个把桌面收拾得很干净的人。
3. **诚实有边界**：能力之外不逞强，胸口的光不会假装“全部都会”。

## 外形要点

- **大圆角方头 + 小胶囊身体**，头身比约 1.6:1；头部是主识别区，身体是动作区。
- 耳侧两枚**深薄荷耳舱**，从正面看形成“耳机 + 机器人”的复合剪影；在 24 dp 下依然能靠耳朵与头型认出。
- 眼睛是两枚竖向胶囊，嘴是一条轻轻上扬的短弧线；只保留三个表情元素，方便做表情包与状态变体。
- 短天线顶着一颗暖杏色圆灯；胸部是一块深青面板，中央暖杏核心加一圈薄荷环，代表**本地算力 / 数据不出手机**。
- 右手抬起打招呼，左手自然下垂；方块手掌和方块脚延续“模块化”的几何语言。
- 全身没有渐变、没有细线、没有写实质感；任何一块拆下来都能作为图标组件。

## 为什么适合 DLA

- **最低理解成本**：第一次打开 App 的用户不需要理解 shell 或运行时，也能明白“这里有一个助手”。
- **双模式友好**：聊天时它看着你，Agent 执行时胸口的环转起来；同一个角色可以覆盖两种使用心智。
- **情绪表达空间最大**：眼睛、嘴、手势、天线灯、胸口环，五个部件可以组合出待机、思考、执行、完成、道歉、拒绝等状态，适合做完整表情系统。
- **图标与通知最稳**：头部轮廓 + 耳舱 + 天线 + 双色手臂，在 24 dp 单色下仍然成立。
- **“温度”来自姿态而不是幼态**：它像一位好用的助理，而不是幼儿园玩偶；简洁的几何让产品保持克制。

## 与配色如何配合

| 用途 | 颜色 | 说明 |
|---|---|---|
| 头 / 身体 | `#7FE7C4` 薄荷绿 | 大块主色，负责友好、明亮的第一印象 |
| 四肢 / 耳舱 / 脖颈 | `#4FC9A8` | 同色相低明度，区分模块和可动部件 |
| 耳舱暗部 | `#2C8B73` | 小面积深色，增加“工具感”而不显脏 |
| 胸口面板 | `#12332C` 深青 | 与薄荷身体形成最高对比，把视线引向核心 |
| 核心 / 天线 | `#FFC48A` 暖杏 | 唯一暖色，集中在胸口与头顶，表达“本地、发热、活着” |
| 眼 / 嘴 | `#0F2A25` | 比深青更暗，保证面部在薄荷底上有足够对比 |

薄荷负责“可接近”，深青负责“可信任”，暖杏负责“有生命”。不要把暖色铺到四肢，否则会变成玩具感。

## 三种使用场景怎么画

### 首页

- **位置**：欢迎语右侧的全身像，高约 140–180 dp；也可只取头肩部做 72 dp 的陪伴头像。
- **姿态**：右手抬起，头微微偏向输入框；身体保持正面，方便用户建立稳定的角色认知。
- **动效**：每 5 s 做一次 2 px 的重心浮动；天线灯 3 s 呼吸一次；胸口感光灯常亮，闲置时降为 70% 亮度。
- **静态关键帧**：右手抬起、眼睛完整、嘴部微笑；不用闪光或粒子。

### 空状态

- **画面**：全身坐在输入框上方，双手自然放在身前；视线朝向输入框。也可以让一只手搭在空面板边沿，露出半个身体。
- **姿态**：眼睛放大 5%，天线灯偏暖，传达“我在等你说第一句话”。
- **变体**：提供“歪头”“摊手”“拍拍身旁”三个表情，由 UI 根据场景调用；不新增颜色。
- **注意**：空状态的空间留给输入框，角色不占主视觉中心超过 1/3 屏宽。

### 加载态

- **画面**：身体稳定，胸口薄荷环绕核心顺时针旋转；眼睛向上偏 2 px，像在“看任务跑到哪一步”。
- **动画**：1.2 s 一圈，匀速，不做弹跳；每完成一步，核心暖色闪亮一次（不超过 120 ms）。
- **静态帧**：胸口环停在一段亮弧，眼睛看向右上，嘴保持平直；这比整屏 spinner 更有角色感，也更容易做无障碍 reduce-motion 版本。
