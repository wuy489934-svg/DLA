# v2 · 溟灯（Ming）— 深海信标

> **一句话设定：** 一盏在深海里独自巡游的小信标，不解释、不催促，只把胸口的光稳稳留在你这边。

## 性格 3 条

1. **安静**：不抢话、不卖萌；存在感来自稳定的明灭，而不是大动作。
2. **敏锐**：光线先于语言到达；任务有变化时，先变的是核心的亮度与尾部的水流。
3. **笃定**：一旦锁定方向就不再左右摇摆，适合表达“本地执行、结果可靠”。

## 外形要点

- **蝠鲼式宽翼**提供一眼可辨的横向剪影；翼缘完整、厚实，不靠细线勾边。
- 中央是一枚**多面体灯芯**：外层雾薄荷光环，内层钻石形薄荷晶体，正中心一颗暖杏色火点。它是眼睛、心脏，也是“信标”本体。
- 一条**不对称飘带尾**从身体下缘向右后方延伸，平衡左上方钓竿式触须带来的偏重。
- 头顶触须挂一颗雾薄荷小灯，暖杏火点藏在内核；这是角色唯一的“表情器官”。
- 没有传统五官，情绪由**核心明度 + 触须角度 + 尾摆方向**表达，避免把神秘感做成可爱脸。
- 只使用大块实心形状和负空间；在视觉上更像一枚会呼吸的徽章，而不是插画角色。

## 为什么适合 DLA

- **“本地”= 深海**：数据不出手机，像一个安静的深海生态，不打扰、不暴露；信标的光只在内部亮着。这比常见的“盾牌 / 锁”更含蓄高级。
- **“智能”= 光**：不需要把 AI 画成大脑或星星，光本身就是计算、感知和回应的隐喻。
- **双模式**：对话时触须像在轻轻听；Agent 执行时，光沿翼缘向尾部流动，表达“任务正在深入”。
- **气质差异**：在三个方案里承担“品牌的高级面”，适合高价值、私密、长时陪伴的叙述。
- **克制**：没有脸，也没有幼态比例，不冒犯专业用户；放在深墨绿界面里尤其成立。

## 与配色如何配合

| 用途 | 颜色 | 说明 |
|---|---|---|
| 深色身体 | `#12332C` | 像海沟里的阴影，让翼缘的薄荷光显得更亮；在深底上作为微妙的暗面 |
| 双翼 | `#7FE7C4` 薄荷绿 | 大块主色，负责 silhouette 和小尺寸远读 |
| 翼缘高光 / 暗鳍 | `#A9F5DF` / `#4FC9A8` | 用两个邻近明度塑造折叠与层次，不引入新色相 |
| 灯芯外环 | `#D5FFF2` 雾薄荷 | 最亮的一层，只在视觉中心使用，制造“发光”错觉但不靠渐变 |
| 火点 | `#FFC48A` 暖杏 | 全图唯一的暖色，面积最小、温度最高；在深海里像一座灯 |

薄荷与深青的冷暖关系固定：**冷色承担形体，暖色承担生命**。不要给双翼加暖色，否则会失去安静的对比。

## 三种使用场景怎么画

### 首页

- **位置**：问候区上方或输入框右侧的悬浮体，占宽 180–220 dp；周围留足 1.5 倍身位的空白。
- **姿态**：翼展开但不僵硬，触须朝向对话输入区，尾带自然垂落；整体重心略低，像在“悬停”。
- **动效**：6–8 s 一个周期的缓慢上下漂移（3–5 dp）；核心每 4 s 做一次 10% 的亮度呼吸；触须只做 2° 左右摆动。
- **静态关键帧**：翼缘高光完整，核心暖点清晰，尾部保持在画面内，不切出边界。

### 空状态

- **画面**：只保留“核心 + 双翼上半部”的半身剪影，背景大面积深墨绿；在翼缘内侧用一段薄荷微光引导视线到输入框。
- **姿态**：核心略暗（约 70% 亮度），触须收起，像在深海中等待一次信号。
- **情绪**：不是空荡，而是“安静的待机”。
- **实现**：可以用主 SVG 的 `body`、`wings`、`lantern` 分组缩放裁切，避免另画一张图。

### 加载态

- **画面**：身体保持不动，核心的薄荷环缓慢收缩 / 扩张；一段薄荷光从左侧触须沿翼缘向尾部流动，像洋流经过。
- **动画**：1.8 s 一次，线性循环，无弹跳；核心暖点保持稳定，不闪烁，传达“在算，但不慌”。
- **静态帧**：触须与核心最亮，尾部末端留一小段高光，暗示路径仍在延伸。

## 小尺寸策略

- 通知栏 / 状态栏使用 `mono-512.png`：完整的蝠鲼轮廓、中央负形眼窗、触须与飘带尾仍在；内部层次全部舍弃。
- 16–24 dp 下不添加鳍纹、光点或文字，保持“宽翼 + 中心窗 + 尾部曲线”三件事即可。
