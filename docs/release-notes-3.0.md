# DLA 3.0 更新说明

## 一句话

设置页重排成一眼能分清的卡片；朗读只保留系统语音和阿里云百炼的 Qwen3-TTS；朗读默认关闭；
README 补上了 LLM 区亮点、DSH 的使用占比和作者定位，然后正式发布。

## 设置页

- 每个区块一张卡片：**模型接口 / 外观 / 对话 / 朗读 / 角色设定 / 更多**。
- 卡片有左侧强调条、标题和一句说明，间距统一，长列表也能快速定位。

## 朗读（TTS）

- 引擎只有两个：**系统语音（本机）** 与 **Qwen3-TTS（阿里云百炼）**。
- Qwen3-TTS：填百炼 API Key，选北京/新加坡区域，选音色（Cherry / Serena / Ethan / Chelsie，可自定义），
  模型默认 `qwen3-tts-flash`；可先「试听」再保存。
- 单次请求上限 600 字：长回复按句子切成多段合成，再连续播放。
- **朗读默认关闭**；从 2.x 升级会强制关闭一次，之后由用户自己打开。
- 每条助手正文下仍有「🔊 朗读」，再点停止。

## 文档与开源

- README 新增「LLM 区：不只是聊天框」「这个工程是怎么用 DSH 做出来的」「作者的实际定位」「完全开源」。
- 文档里明确了 DSH 工具的使用场景与大致占比，以及作者的职责边界。
- 运行时二进制仍由脚本下载，不进入仓库；许可证见 `THIRD_PARTY_NOTICES.md`。

## 升级提示

- 覆盖安装保留会话、人设与 API Key；朗读开关会被重置为关闭。
- 重装后系统无障碍开关可能被清掉，需要重新打开（Agent 用）。
- 仅支持 arm64-v8a，APK 约 48 MB。
